# AI-Powered Customer Support Chatbot

An NLP-based customer support chatbot built using Python, Flask, NLTK and SQLite.

## Features

- NLP-based FAQ matching
- Customer support responses
- Interactive web chat interface
- Conversation logging
- SQLite database
- REST API
- Responsive design

## Technologies

- Python
- Flask
- NLTK
- SQLite
- HTML
- CSS
- JavaScript
